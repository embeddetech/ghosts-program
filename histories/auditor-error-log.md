# Auditor-error log (hallucinated/incorrect findings, caught before application)

Central registry for the meta-research dataset: every audit-proposed
finding that was REJECTED under release-gate rule 7 (verify factual
corrections against primary sources before applying) or refuted by
direct computation. Companion classes: fetch-misreads the agent
itself caught and corrected mid-audit, and self-caught derivation
slips. Per-paper ledgers carry the same events in context; this file
is the cross-paper index.

Classes:
- FABRICATION — asserted a fact with no basis in any record
- MISREAD — read a real record incorrectly (incl. tool-fetch artifacts)
- WRONG-RULE — applied the wrong governing record (e.g. arXiv over publisher)
- WRONG-MATH — proposed a mathematically incorrect "fix"
- SELF-CAUGHT — agent detected and corrected its own error before reporting
